# Real Estate Market Analysis
Real-world real estate data analysis using Python, exploratory data analysis, statistics and data visualisation.


## Project Overview

This project explores real estate data to identify patterns in property prices, locations, property types and other 
key market characteristics. The analysis uses Python, Pandas, NumPy, Matplotlib and statistical techniques to transform 
raw data into insights that can support better understanding of real estate market trends and decision-making.


## Business Objective
The objective is to analyse real estate data to understand the factors and market patterns associated with property prices, 
identify meaningful trends across locations and property types, and generate insights that could support data-driven real estate decisions.


## Tools & Technologies

- Python
- Pandas & NumPy
- Matplotlib
- Statistical Analysis


## Key Analysis Areas
- Data cleaning and preparation
- Exploratory data analysis
- Property price analysis
- Geographic and regional patterns
- Property type comparisons
- Statistical relationships and trends
- Data visualisation
